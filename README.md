# כשאחים שוכחים – ניהול מחלוקות בעם

אפליקציה כיתתית חיה לתוכנית „אני ישראלי”.

**שאלת השיעור:** איך מנהלים מחלוקת קשה מבלי לפרק את הבית המשותף?

מבנה האפליקציה:
1. למידה בחברותא – 8 קבוצות, 8 סיפורי מחלוקת, העלאת רקע / תוצאה / כלל.
2. ענן מילים כיתתי – עד 3 מילים לכל תלמיד או קבוצה לשאלה „מה חוזר שוב ושוב?”.

מסך המורה שולט בשלב הפעיל, פתיחה וסגירה, QR וקוד כיתה, איפוס ותצוגת תוצאות בזמן אמת.
